# Mike Ayles

Head of Product Development at addvantage, Tribune Group. Building dual-fuel diesel-LPG conversion systems for commercial fleets. Primarily embedded software engineering, but also data analysis and homologation. Approaching 30 million miles deployed.

Building a FPGA stereo depth camera targeting ISO 13849 PLd Cat 3 for collaborative robotics. Custom SGM in Verilog on AMD K26.

Built [Phaestus](https://phaestus.app) for the Gemini3 Hackathon. I found LLM driven hardware design too compromised at the moment, but found success by constraining to asking the LLM to be an assembler of fixed design blocks. Successfully manufactured a battery powered BLE remote control, with 2x PCB's, power management, 3d printed enclosure and embedded firmware. 

Background is sport science. Got into embedded by accident in 2014. Self-taught from there.
